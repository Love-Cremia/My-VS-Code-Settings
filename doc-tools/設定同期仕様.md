# VS Code 設定同期スクリプト仕様

## 概要

VS Code のユーザ設定ファイル (settings.json) と，このプロジェクトで管理している設定ファイルを同期するスクリプト．

プラットフォーム別に異なるスクリプトが用意されています：

- **Windows**： `sync-vscode-settings.bat`
- **macOS**： `sync-vscode-settings.command`

## 関係ファイル構成

```plaintext
. # Project Root
├── sync-vscode-settings.bat # Windows 用バッチファイル
├── sync-vscode-settings.command # macOS 用シェルスクリプト
└── UserSettings/
    ├── my-settings.jsonc # 本番ファイルは settings.json だが区別のため頭に my- とつけ，拡張子も jsonc にしている
    ├── VS-Code/ # ホームディレクトリ直下に配置するフォルダ
    │    └── .markdownlint.jsonc
    └── Backup/ # GitIgnore 対象 (バックアップ) 
        ├── settings_yyyyMMdd-HHmmss.json
        └── ...
```

## VS Code 設定ファイルのパス

- `settings.json` についてはデフォルト値から変えない
    - Windows の場合は `%APPDATA%\Code\User\` 
    - Mac の場合は `~/Library/Application Support/Code/User/`
- その他の設定ファイルは `settings.json` 内に Mac, Windows の両方で同じパス指定ができるように，
`~/VS-Code` というフォルダを作成して用いる

## 処理ステップ

### 1. スクリプト起動時

実行するとまずどちらからどちらへの同期かを聞かれます：

```PlainText
同期方向を選択してください:
  1) VS Code の設定を Git に保存
  2) Git の設定を VS Code に反映
```

### 2. 方向 1: VS Code → Git (設定をプロジェクトへ保存)

- VS Code の実際の設定ファイルをプロジェクトの `/UserSettings/my-settings.jsonc` にコピーします
- ホームにある `VS-Code` フォルダも同様にプロジェクトの `/UserSettings/VS-Code` にコピーします
- バックアップ作成は不要です (Git で過去バージョンの履歴が管理されているため)

### 3. 方向 2: Git → VS Code (設定をプロジェクトから適用)

1. まずバックアップを取得します
    - 既存設定 (VS Code の現在の `settings.json` と，ホームにある `VS-Code` フォルダ) をそのままプロジェクトの
    `/UserSettings/Backup/` にコピーし，ファイル名・フォルダ名を日時付き (サフィックスに `yyyyMMdd-HHmmss` をつける) に設定します
2. プロジェクトにある設定ファイル類を VS Code のフォルダに上書きコピーします
    - `/UserSettings/my-settings.jsonc` を実際の VS Code の `settings.json` に上書きします
    - `/UserSettings/VS-Code` も同様にホームディレクトリに上書きします
    - 確認メッセージは表示されません

## 実装上の注意点

- **エラーハンドリング**： 設定ファイルが見つからない場合，またはコピーに失敗した場合は，エラーメッセージを表示して処理を中止します
- **バックアップ命名**： 同一秒内に複数回実行される場合に備えて，衝突を避ける工夫があります (プラットフォームによって異なる場合があります)

## 使用方法

### Windows

`sync-vscode-settings.bat` をダブルクリック，または PowerShell/コマンドプロンプトから実行します：

```powershell
.\sync-vscode-settings.bat
```

### macOS

`sync-vscode-settings.command` をダブルクリック，またはターミナルから実行します：

```bash
./sync-vscode-settings.command
```

もしくは，実行権限を付与してから実行：

```bash
chmod +x sync-vscode-settings.command
./sync-vscode-settings.command
```
