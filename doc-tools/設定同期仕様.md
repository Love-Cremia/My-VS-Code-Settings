# VS Code 設定同期スクリプト仕様

## 概要

VS Code のユーザ設定ファイル（settings.json）と，このプロジェクトで管理している設定ファイルを同期するスクリプト．

プラットフォーム別に異なるスクリプトが用意されています：
- **Windows**： `sync-vscode-settings.bat`
- **macOS**： `sync-vscode-settings.command`

## 関係ファイル構成

```plaintext
. # Project Root
├── sync-vscode-settings.bat # Windows 用バッチファイル
├── sync-vscode-settings.command # macOS 用シェルスクリプト
└── UserSettings/
    ├── my-settings.jsonc # このリポジトリで Git 管理するファイル．区別のため頭に my- とつけている
    ├── .markdownlint.jsonc # このリポジトリで Git 管理するファイル
    └── Backup/ # GitIgnore 対象（バックアップ）
        ├── settings_yyyyMMdd-HHmmss.json
        └── ...
```

## VS Code 設定ファイルのパス

| プラットフォーム | パス |
|---|---|
| Windows | `%APPDATA%\Code\User\settings.json` |
| macOS | `~/Library/Application Support/Code/User/` |

## 処理ステップ

### 1. スクリプト起動時

実行するとまずどちらからどちらへの同期かを聞かれます：

```
同期方向を選択してください:
  1) VS Code の設定を Git に保存
  2) Git の設定を VS Code に反映
```

### 2. 方向 1: VS Code → Git（設定をプロジェクトへ保存）

- VS Code の実際の設定ファイルをプロジェクトの `./UserSettings/my-settings.jsonc（または my-settings.json）` にコピーします
- `.markdownlint.jsonc` も同様に VS Code の設定から `./UserSettings/.markdownlint.jsonc` にコピーします
- バックアップ作成は不要です（Git で過去バージョンの履歴が管理されているため）

### 3. 方向 2: Git → VS Code（設定をプロジェクトから適用）

1. まずバックアップを取得します
   - 既存設定（VS Code の現在の settings.json）をそのままプロジェクトの `./UserSettings/Backup/` にコピーし，ファイル名を日時付き（`settings_yyyyMMdd-HHmmss.json` 形式）に設定します
   - `.markdownlint.jsonc` も同様にバックアップディレクトリにコピーし，ファイル名を日時付き（`markdownlint_yyyyMMdd-HHmmss.jsonc` 形式）に設定します
   
2. `./UserSettings/my-settings.jsonc（または my-settings.json）` を実際の VS Code の `settings.json` に上書きします
   - `.markdownlint.jsonc` も同様に VS Code の `.markdownlint.jsonc` に上書きします
   - 確認メッセージは表示されません

## 実装上の注意点

- **ファイル形式の自動検出**： プロジェクト側に `my-settings.jsonc` と `my-settings.json` の両方が存在する場合は，`.jsonc` を優先的に使用します
- **エラーハンドリング**： 設定ファイルが見つからない場合，またはコピーに失敗した場合は，エラーメッセージを表示して処理を中止します
- **バックアップ命名**： 同一秒内に複数回実行される場合に備えて，衝突を避ける工夫があります（プラットフォームによって異なる場合があります）

## 使用方法

### Windows

`sync-vscode-settings.bat` をダブルクリック，または PowerShell/コマンドプロンプトから実行します：

```powershell
.\sync-vscode-settings.bat
```

### macOS

`sync-vscode-settings.command` をダブルクリック，またはターミナルから実行します：

```bash
./sync-vscode-settings.command
```

もしくは，実行権限を付与してから実行：

```bash
chmod +x sync-vscode-settings.command
./sync-vscode-settings.command
```
